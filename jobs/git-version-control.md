## How to use this job

Git is a solved-knowledge domain — the canonical sources are complete and current. The
value of a *private* fork here is a personal **"git recovery" skill**: the exact commands
for the situations you panic about (recover deleted branch, undo a bad rebase, split a
commit). Build that from Pro Git's content; don't hunt for a magic repo.
