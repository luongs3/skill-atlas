## Tier A 🟢 — Use the agent directly (the real answer for this job)

For English, the highest-trust "skill" is **Claude itself + a private prompt**, not a repo.
English correction/coaching is exactly what an LLM does natively and reliably (unlike
Upwork strategy or system design, where it lacks your context).

**Recommended private skill to build (not public):**
> A `english-coach` skill that: (1) rewrites your draft in natural professional English,
> (2) explains *what changed and why* so you learn, (3) keeps a running log of your
> recurring mistakes. Build it with the official **skill-creator**
> (https://github.com/anthropics/skills/tree/main/skills/skill-creator, Tier A, validated 2026-06-02).

This is the cleanest example of the atlas's core thesis: **the public layer is thin, so the
value is the private fork.** Don't hunt for a magic English repo — build the coach skill.
